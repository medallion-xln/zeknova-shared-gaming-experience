# W0-AF — Forest Defensive Action Registry

This phase defines the first ZekNova-native ZekNovan settlement macro-action space for the Forest AO.

It consumes only the W0-O.3 faction observation packet and produces a canonical, read-only candidate set plus deterministic one-step outcome projections. It does not execute actions or mutate the live game.

The registry contains 13 defensive actions: perimeter hold, route patrol/reconnaissance, hostile interception, combat screening, structure reinforcement/repair, route fortification, resource security, infrastructure stabilization, intelligence sharing, defensive diplomacy, and tactical withdrawal.

All cost and outcome values are planning-contract values. W0-P must establish parity with live ZekNova before they can be treated as an authoritative transition model.
