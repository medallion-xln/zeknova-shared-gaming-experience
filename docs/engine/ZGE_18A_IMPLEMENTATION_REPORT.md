## C. Required behaviors

`npm run test:runtime:behaviours`: **32/32 pass** (ZGE-18A.2 certifies fourteen RB-1 disposal-fence tests that run the verbatim class `dispose()` and the segment 03/04/06 wrapper chain; the zR constructor is not instantiated). The harness extracts and executes verbatim source-derived candidate functions, rather than a duplicate implementation. VM modules supply a fixture environment module, real Three vectors/math, world collaborators and a controlled clock. No test sleeps for 20 seconds.

- **RB-1:** Preserve the 3,000 ms HQ wait; cover success, unresolved/rejected loads, late completion, disposal during HQ/import waits, superseding loads and staged-wrapper behavior. Testing discovered a later wrapper still awaited HQ indefinitely. The candidate now bounds that wrapper, retains the 5,500 ms staging pause, skips a redundant inner HQ wait, catches rejected HQ for procedural fallback, and fences disposal around staging. This explicit failure-path correction is recorded separately from shipping bytes; it was not deployed or silently substituted into the launch path.
- **RB-2:** Preserve the 20,000 ms readiness race. Cover normal completion, unresolved environment readiness, exact timeout, import/decode rejection, base-init rejection, late module completion, disposal and token-based attachment cancellation. Underlying network work is not aborted. Late environment disposal can run twice, preserving the existing idempotent-disposal requirement.
- **RB-3:** Preserve shipping timer placement and real collision/crash/recovery functions. Cover unblocked progression and expiry, terrain/player/building/rock/actor collisions, repeated obstruction, recovery termination, state mutation during animation, and cleanup/model replacement. Both old and shipping collision helpers already transition to recovery; the old permanent-soft-lock explanation was removed. Shipping semantics include decrementing the newly set recovery timer in the collision frame and completing the current charge branch after an animation callback changes state.

These are focused function-level regressions, not certification of every game lifecycle path or GPU resource plateau. Movement mechanics, mission progression and boss design were not changed.
