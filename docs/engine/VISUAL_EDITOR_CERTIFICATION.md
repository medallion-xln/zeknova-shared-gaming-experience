# Visual editor certification

Studio's desktop vertical slice is executable at `/examples/studio/`. Certification uses installed Playwright and actual Google Chrome pointer/keyboard input, not synthetic DOM state changes. The renderer's read-only projection helpers locate entity/handle screen coordinates; Playwright then performs real mouse hit tests. Test assertions read the public local store after those interactions. Raw request inventories, screenshots and failure logs accompany the report.

Both WebGPU auto selection and explicitly forced WebGL pass the same workflow: project loading/rendering, viewport explorer selection, hierarchy selection, highlighted handles, physical X-axis drag, temporary-presentation isolation before pointer release, transaction commit, undo/redo, numeric position/rotation/scale editing, invalid negative-scale rejection with identical prior state, browser-storage save/reload across a page reload, prefab create/delete/undo, mock preview/reject/approve/provenance/undo, isolated simulation movement/pause/step/reset, event filtering and keyboard panel resizing. Both X and Z handles are exercised with physical pointer drags. Numeric edits and controls provide keyboard alternatives.

The independent project runs movement, collection and the build objective with physical keyboard input on both backends. Browser request inventories reject minified legacy game or private source imports. Five saved-scene reload cycles verify bounded observed live geometry counts. This is a small ownership observation, not a full GPU leak certificate or proof of GLTF/model disposal across every game.

Three source ownership was corrected after the first full suite rejected a direct SDK Three import. The adapter now requires an explicitly injected shared namespace; the pre-existing canonical dependency assertion passes unchanged. No test is weakened. Other retained diagnostics include a repeated-undo test that over-counted available history, a hierarchy timeline omission fixed in the UI, and an objective keyboard fixture that released B before a simulation step; the fixture now holds it until the actual rule commits. A later Z-axis drag exposed numeric step validation rejecting untouched fractional coordinates; numeric controls now accept any finite precision and the component schema still validates them. Failed attempts remain evidence.

The full existing engine suite, 86-file legacy classification and nine existing browser regression scripts are rerun. Legacy movement/building/boss, WebGPU/WebGL, native/reference/mock fallback, save/network, parity and lifecycle assertions remain active. The three known golden mismatches are preserved. See final report/manifest for exact counts and logs.

Boundaries: local flat scenes and procedural primitives, XZ translation gizmos, numeric Euler rotation/positive scale, one browser profile's storage, trusted project code. Unsupported: general rotation/scale handles, camera orbit tools, parenting, arbitrary asset import, visual logic graphs, multiuser authoring, live publication, rewind of all gameplay systems, production identity and accessibility conformance certification. No empty Logic tab implies unsupported features work.
