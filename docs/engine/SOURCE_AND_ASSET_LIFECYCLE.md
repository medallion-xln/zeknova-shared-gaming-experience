# Source, packaging and asset lifecycle

ZGE-10 adds a separately distributable public SDK without claiming reconstruction of the original minified game. `scripts/zge10-build.mjs` bundles the public core and rendering adapter twice and compares bytes. The source closure is 22 readable files including SDK, kernel/assets dependencies, original SDK tests and independent project rules/manifest. `scripts/zge10-clean-build.mjs` copies that closure into a fresh private environment, runs offline package-lock generation and clean `npm ci` for pinned esbuild 0.25.11/Three 0.185.0, builds twice, compares two npm package tarballs, installs the packed public SDK and runs all 11 public tests plus an independent consumer smoke check. No root `node_modules`, old bundle or ZekNova gameplay source is needed by that consumer.

The retained clean environment/archive has a source SHA inventory, dependency lock, reproducible ESM hashes and packed-file list. This demonstrates the recorded Node 22.22.2 toolchain and available offline npm cache, not arbitrary compiler/OS byte identity or a public registry release. Build-time core/assets source is captured; consumer-time imports resolve only the installed public `dist` entrypoints. The browser adapter imports no Three copy; the application supplies the single shared r185 namespace. Existing legacy embedded duplication remains unresolved.

The earlier authority capture was also rerun: 79 readable engine/authority/tool files, 64 selected tests, 19 PHP syntax checks and repeated standalone ESM. Its source manifest identifies current worker telemetry changes. This boundary excludes the browser distribution and complete original game; the new SDK clean build complements rather than relabels that historical capture.

Project manifests declare stable public asset IDs, relative paths and SHA-256 syntax; scene asset components reject unknown IDs. `assetReference` and `acquireAsset` resolve through that manifest into the existing AssetService. Asset format loaders and byte-hash verification remain explicit host responsibilities. The independent project uses procedural primitives only and needs no external media or credentials.

Tests prove coalesced shared parsed load, independent mutable animation/bone-state clones, lease release, zero-budget eviction and disposal, invalid/unknown asset reference atomicity and owned renderer disposal. Shared parsed `.value` is a trusted read-only convention; callers must not mutate it. Detached `.instantiate()` returns loader-owned state, and clone/disposal correctness for arbitrary third-party loaders remains the host's responsibility. Studio reuses primitive geometries, disposes removed mesh materials, clears proposal ghost materials and disposes its context, helpers and geometries on page exit. Five observed reload cycles have bounded geometry counts; longer/model-heavy GPU teardown is still open.

The established GLTF watchdog, cancellation, timeout and native fallback implementations and assertions remain unchanged. No production asset redistribution/licensing or model-weight provenance claim is made. No generated legacy bundle or golden assertion is modified. Failed source capture into a nonprivate parent was refused as designed, retained, and repeated under a new owner-private parent.
