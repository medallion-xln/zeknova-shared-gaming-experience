## One writer and explicit exclusions

`ConstructionPort` keeps its runtime private. ENGINE dispatch is allowed only at the `source-world` boundary. LEGACY and SHADOW dispatch cannot mutate that runtime; `observe` evaluates a detached candidate and returns frozen facts without presentation publication. Conflicting/ill-typed authority flags reject. A live boundary cannot activate ENGINE. The existing live adapter independently rejects `construction=engine`; no new live method or prototype patch was introduced.

The PHP worker and standalone gameplay session both instantiate this port. PHP is the only durable world writer: it serializes arrivals, authenticates the player, checks the receipt before dispatch, commits the complete candidate and publishes only confirmed state. Browsers run a read-only kernel replica. JavaScript imports are trusted code, not a hostile-plugin sandbox; authority flags do not revoke arbitrary access held by the historical live bundle.

Four new contract tests certify source ownership/flag conflicts, immutable shadow evaluation, quarantine before cost, and the full independent selection/placement/mission/reward/removal/compaction/restore/presentation sequence. Existing oracle and failure-injection fixtures remain intact. The independent domain is usable within its stated content policy; **complete live construction parity remains incomplete**.
