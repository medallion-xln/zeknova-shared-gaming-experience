# Source-owned gameplay demo — ZGE-05

Launch `npm run dev`, then open `http://127.0.0.1:8790/examples/construction-world/`. The page is Construction Valley, a connected 3D vertical slice using core/kernel, ConstructionRuntime, mission reducer, WorldCheckpoint and existing rendering adapters. It imports the vendored Three module, **never** `assets/index-02987539.js` or live ZekNova content. The previous V2 transaction lab remains at `examples/construction-world/v2.html`; its original assertions still run there. The Node `npm run demo:engine` fixture also remains.

1. Focus the world and use WASD/arrows. Gold capsule is the player; rocks, world bounds, water and structures block movement.
2. Select shelter (4 stone) or beacon (6), click terrain or enter X/Z and Place. Occupied/outside/poor requests reject without cost. Gather +8 uses the same command boundary.
3. Build two structures to complete First Colony and gain 25 XP once. Removing a structure frees occupancy without refund or repeated reward.
4. Save locally. Only a completed adapter acknowledgment reports success. Reload restores exact player/building IDs, inventory, mission, receipt/event journals and reward IDs. Verify replay compares all of that state against replay from the same example content.
5. Inspect ordered world events/revisions or Capture reference. Request as Bob submits another local builder's command to the **same** authority/world/balance; this button is not a network server. The separate two-client server fixture supplies network-condition evidence.
6. Restart scene reconstructs presentation while retaining authoritative state. Dispose owns listeners, RAF, geometries/materials, renderer and session/kernel command registration. World snapshots drive rendering; no mesh transform drives gameplay.

Public source: `world.js` owns example content/terrain; `gameplay-session.js` uses the manual kernel command queue and a single runtime; `scene.js` consumes immutable snapshots; `gameplay-ui.js` owns DOM/input/RAF. The RAF presents and samples input, while each queued input executes in the kernel's manual fixed step. No second simulation loop runs. Gold movement is a bounded deterministic command delta, not a general rigid-body controller. Example supplies are a developer grant, not a harvest simulation.

Rendering: one independent WebGL2 renderer, shared by NativeRenderer and ReferenceRenderer. The native adapter now correctly identifies direct WebGLRenderer instances. Existing live WebGPU and safe WebGL paths remain tested separately. Capture carries simulation time/revision/camera metadata; no scene mesh is serialized. `?present=neural` with no configured backend explicitly falls back to NATIVE through the existing PresentationController. Existing mock labeling/frame sequencing tests and live mock capture remain unchanged; no inference service, weights or training introduced.

Storage key `zge.independent-world.v3`, envelope `zge.world-checkpoint.v1`, runtime snapshot `zge.construction-runtime.v1`; these do not overwrite V2's key or production v4 saves. Restore rejects unsupported/corrupt versions instead of silently reinterpreting them. Long-running compaction/content-version migration remains future work; this is a bounded developer world, not a production persistent shard.

Browser evidence: `browser-source-world.json` and `standalone-3d.png`. Physical keyboard/form/canvas controls, placed-building collision/removal, resources, mission/reward uniqueness, local acknowledgment/reload, full deterministic replay, lit reference capture, native fallback, three scene restarts and disposal are asserted. Listener counts, renderer geometry counts, frame samples and one RAF loop are captured. Existing V2 browser assertions are preserved with only their URL moved to V2's archived page.
