# Component schemas and reflection

A portable definition has `schema:'zge.component.v1'`, label and fields. Each field declares number, boolean, string, enum, vector, asset or entity; optional/nullable, numeric bounds, string length, enum values, vector dimension, readOnly and permission metadata are supported. Unknown field types and malformed definitions fail. Plain finite JSON is required throughout. Optional `additionalProperties:false` rejects undeclared data.

`registerComponent(name,definition)` creates its validator and portable metadata. The legacy `(name,validator,metadata?)` form remains supported for trusted host validators; arbitrary function semantics cannot be recreated from JSON, so portable definitions are preferred. `componentSchemas()` returns detached definitions. Standard definitions cover transform, primitive mesh, collider, generic state, asset reference and editor hierarchy. Generic state without field metadata remains a read-only JSON inspection rather than a misleading editor.

Studio derives component forms from these public definitions. Number/vector fields accept finite arbitrary precision; booleans use checkboxes, enums/references use selects, strings use text inputs. The existing transform numeric controls use the public transform metadata. Unsupported/unavailable fields are not silently writable. Component apply creates one atomic multi-property update. Invalid data leaves the scene and history unchanged.

`editProperties` checks reflected fields, readOnly and named permission grants before committing. `inspectEntity` removes private player/team/AI data and metadata-protected components/fields unless the synchronous host policy permits them. Studio uses that filtered view for its inspector. Raw scenes are trusted authoring data, so these checks do not sandbox a malicious plugin with direct Scene access. Local plugins remain trusted executable code.

Asset/entity references validate against current registries/entity identities at transaction commit. Parent references cannot dangle or cycle; deleting referenced entities must remove/update references in the same batch. Numeric readonly fields in Signal Garden are updated by trusted simulation rules but disabled in the authoring inspector. Its custom component exercises all seven representative field types. Public tests verify schema persistence, denied secret/readOnly edits, invalid atomic updates and clean restored validation.
