# Advanced editing contracts — ZGE12

Ctrl/⌘ click toggles hierarchy rows; Shift click extends a visible hierarchy range. Arrow/Home/End navigation operates in the virtualized list and retains actual focus; Tab can leave it. Selection count is visible. The inspector's Selection offsets panel applies numeric local XYZ offsets to1–100 unique unlocked transform entities. One public `Scene.batchTransform` commit moves all; one undo restores all, and redo restores the batch. Empty/duplicate IDs, missing transforms, locked entities, nonfinite/out-of-range values, partial failures and stale revisions reject before mutation. A zero offset is a semantic no-op.

Offsets are applied in each entity's local coordinates. Selecting both parent and child can therefore change their combined world displacement. This is an explicit local offset operation, not a shared-pivot world group gizmo. Existing single-entity gizmo preview, Escape cancellation and atomic release remain intact. Box selection, multi-object gizmos, nested prefab propagation and batch duplication are unsupported.

Existing prefab identity, detached instances and component override reporting remain. Missing prefab identities now reject scene restore before replacing a working scene. No unversioned nested propagation/apply-revert system was introduced. Safe subtree deletion remains the existing confirmed workflow; selection batching does not claim new subtree semantics. Scenes stayv1, projects stayv2 with preview12 compatibility.

Mock changesets retain explicit preview/approve/reject, plan/diff, stale conflicts, unsupported components/assets, whole-batch validation, provenance and one-step undo. New tests exercise two-entity proposals, cancellation, stale approvals and a valid first operation followed by an invalid dependency/component; no partial state is committed. Imported JSON cannot execute code. No provider/model inference or autonomous persistent-world authority exists.

Physical tests exposed a virtual scroll focus loss; preserving the focused row when replacing the window fixed Arrow/Home/End navigation. Repeated identical project selection required clearing the consumed file input;24-switch tests now pass. Failure logs are retained. Compatibility validation tightens missing-prefab and duplicate-path behavior; malformed prior files may require repair, while supported Signal Garden/Outpost files still pass.
