# Static model import certification — ZGE12

**PASS_BOUNDED_STATIC_GLB2; general glTF support is not claimed.** The public `inspectGLB`/`engine.importModel` path handles one GLB2 scene/node/mesh with one embedded buffer and1–16 triangle primitives. POSITION/optional NORMAL must be tightly packed float attributes; optional indices are uint16/uint32. Materials support opaque base color and double-sided state. Bake node transforms before import.512KiB source,30000 vertices,1MiB normalized asset and4MiB project limits are enforced.

The parser checks magic/version/declared length/chunk alignment, bounds, accessors, counts, finite coordinates, buffer ownership, valid indices and geometry summaries. External buffers/URLs, images/textures (including missing texture dependencies), extensions/compression, rigs, animation, morph targets, cameras, transformed/nested scene graphs and unsupported materials reject explicitly. Text `.gltf` files are unsupported; arbitrary JSON remains data assets. There is no code evaluation or parser-triggered network fetch. GUI checks file extension/MIME/size before parsing. Public API bytes are content-sniffed by the parser. Content-type claims alone are not trusted.

Normalized geometry and its source SHA-256 become an embedded project asset through the existing AssetService, using canonical JSON SHA, coalesced verified loads, leases and detached instances. Duplicate IDs—including asynchronous races—and duplicate asset paths reject. Failed import leaves the project unchanged. Relative-path validation rejects absolute paths, traversal, URL separators and executable asset types. Static model imports raise older projects to preview12 compatibility. Model data mislabeled preview11 rejects. Encoded traversal, dot/empty path segments and URL-normalization aliases also reject. Source hash records byte custody; it is not a license proof.

Studio previews counts/material data, places actual geometry by native drag or a keyboard-accessible button, creates prefabs and exports/reimports stable IDs. The viewport converts validated model data into owned Three geometry/materials shared across instances, releases them on registry replacement/project close, and releases them again safely on final viewport disposal. Public tests cover detached clones, hashes, leases, failures, refs, prefabs and exact portable roundtrip. Physical browser tests cover both renderer paths and imported-model workflows.24 project switches/backend alternate100-entity/model scenes and empty worlds, observing zero old engine weak references, zero active asset leases and stable returned empty renderer resources.

Fixture geometry is a self-authored triangle declared CC0-1.0. User-imported assets default to unknown redistribution rights; original game assets remain outside this certificate. Advanced commercial models, skeleton/morph/material fidelity, external media packaging and adversarial corpus/fuzz coverage remain untested. The restricted importer rejects unsupported cases; it does not silently render a misleading substitute.
