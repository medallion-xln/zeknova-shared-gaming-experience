# Stage 1A-Z — Forest Objective and Failure-Possible Scenarios

Stage 1A-Z declares the first canonical strategic objective hierarchy for the Forest Defensive stance and certifies seven deterministic scenarios in which poor decisions can fail and objective-relevant decisions can succeed.

The objective hierarchy is lexicographic: settlement survival outranks every lower goal. Critical structure integrity, settlement security, infrastructure, routes, patrol preservation, recovery capacity, resources, and de-escalation follow in that order.

The scenario harness is evaluation-only. It uses the W0-AF action costs/outcomes and requires the W0-P.3 thirteen-action parity closure, but it does not issue live game commands and does not grant Sentinel Prime or the Router any authority.

Certified scenarios:

1. Perimeter Breach
2. Damaged Core Under Pressure
3. Route and Infrastructure Cascade
4. Exposed Resource Corridor
5. Exposed Patrol
6. Core Versus Resource Priority
7. Defensive De-escalation Window

Each scenario must have a deterministic success witness, a deterministic failure witness, and an ablation showing that removing the critical objective-related action causes failure.
