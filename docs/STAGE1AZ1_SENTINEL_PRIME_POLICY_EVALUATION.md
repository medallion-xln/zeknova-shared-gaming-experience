# Stage 1A-Z.1 — Sentinel Prime Policy Evaluation

This phase compares a deterministic 13-action Sentinel Prime PUCT candidate with:

- an explicitly labeled incumbent scripted proxy,
- deterministic defensive rules,
- seeded random legal choices,
- always-hold,
- and one spam control for every Forest Defensive action.

The evaluation runs only inside the seven frozen Stage 1A-Z scenarios. It cannot execute live commands and grants Sentinel no authority.

## Current measured result

Across 16 seeds per scenario, Prime preserved the settlement in every run but completed the scenario objective in 43.75% of runs. The deterministic rule baseline completed 100%, the incumbent proxy 41.0714%, random legal 25%, and always-hold 0%.

Prime's development gate did not pass. This is an evaluation result, not a strategic competence certification.
