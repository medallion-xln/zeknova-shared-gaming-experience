# ZekNova Adapter Migration — Stage 2F-Z

The ZekNova Stage 1A-Z adapter is registered as an external R0 production adapter. Stage 2F-Z does not alter its six-action surface or grant authority. It hardens the evidence campaign needed before controlled evaluation of any candidate policy.

A qualifying campaign must use authentic `live-runtime` provenance, production-eligible captures, exact runtime and repository hashes, self-hashed session manifests, contiguous per-session sequences, no duplicate capture or fixture evidence, full Stage 2E-Z parity, and the configured coverage thresholds.

Only after the campaign passes may candidate recommendations be assessed for legality, source-state immutability, R0 compliance, coverage and latency. A passing candidate packet permits only human-reviewed shadow evaluation. It never authorizes execution.
